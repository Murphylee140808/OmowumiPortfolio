# Omowumi Akindehinde Portfolio

A dependency-free, responsive editorial portfolio for a No-Code Website Designer and Digital Solutions Specialist.

## Run locally

Open `index.html` directly in a browser. No build tools or package installation are required.

## Content configuration

All editable profile and contact settings are at the top of `script.js` in the `profile` object. Projects, services, testimonials, process steps, and FAQs are maintained as data arrays in the same file.

The supplied identity discrepancy is preserved intentionally: the About copy says `Odede John`, while the primary profile and dynamic copyright use `Omowumi Akindehinde`. Footer email display and destination, as well as displayed phone and WhatsApp destination, are separate settings.

The header theme toggle switches between dark and light themes, follows the system preference on first visit, and persists the visitor's choice in `localStorage`.

Project previews are intentionally labeled placeholders because no screenshots were supplied. Replace each `.project-preview` content with the correct screenshot when available.
